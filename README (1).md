# Части речи · 7 класс

Интерактивная рабочая тетрадь по морфологии. 8 занятий, шпаргалка и ключи для учителя.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `chasti-rechi`. Сделайте его публичным.
2. Нажмите **Add file → Upload files** и загрузите `index.html` (и этот `README.md`).
3. Откройте **Settings → Pages**.
4. В блоке **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через 1–2 минуты появится ссылка вида `https://ВАШ-ЛОГИН.github.io/chasti-rechi/`. Её и нужно дать ученице.

Чтобы встроить тетрадь в другую страницу, используйте:

```html
<iframe src="https://ВАШ-ЛОГИН.github.io/chasti-rechi/" style="width:100%;height:90vh;border:0"></iframe>
```

## Как работает ученица

- Вверху она пишет своё имя.
- Задания бывают трёх видов: выбор из списка, вписывание слова, нажатие на слова в тексте. Есть и поля для письменных ответов.
- Кнопка **«Проверить и сохранить»** работает так:
  - задания с выбором сразу подсвечиваются: зелёным, если верно, красным, если ошибка;
  - письменные ответы просто сохраняются.
- Ответы хранятся в браузере. Если закрыть страницу и открыть снова на том же устройстве, всё останется.
- В заданиях «нажми на слова» вторая часть открывается, когда все слова найдены. Если не получается, она откроется после трёх попыток.
- Кнопка **«Отправить учителю»** скачивает два файла:
  - `.txt` – читаемый отчёт со всеми ответами и отметками ✓ / ✗;
  - `.json` – файл, который можно открыть в режиме учителя.

## Режим учителя

- Кнопка **«Для учителя»**, код по умолчанию: `2026`.
- В этом режиме доступны:
  - ключи к письменным заданиям;
  - загрузка `.json` ученицы: страница покажет её ответы с подсветкой;
  - очистка ответов.
- Код меняется в начале скрипта в `index.html`, строка `const TEACHER_PIN = "2026";`.

Важно: код только прячет ключи от случайного взгляда. Это не настоящая защита, потому что файл страницы открыт всем, у кого есть ссылка.
